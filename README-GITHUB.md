# SuperPod Kids website source

The main site entry is `index.html`, styled by `css/style.css`. The `downloads/guides.php` and `press/list.php` endpoints require PHP on the hosting server.

This is a cleaned source copy of the live document root. Historical old versions and macOS metadata were intentionally excluded.

**Publishing is not configured.** Uploading to GitHub does not change the live Namecheap website. Do not deploy until a reviewed deployment procedure and backup are in place.
